## Ejecutar React Jobs en local

Instala las dependencias con `npm ci`. Desde la raíz del proyecto, abre dos terminales.

1. Ejecuta `npm run server` para iniciar JSON Server en el puerto 5000.
2. Ejecuta `npm run dev` y abre la URL que muestra Vite. El puerto predeterminado es 3000.

JSON Server carga las ofertas de ejemplo desde `src/jobs-api.json`.

## Verificar el proyecto

- `npm run lint` revisa el código con ESLint.
- `npm run build` genera la compilación en `dist/`.
